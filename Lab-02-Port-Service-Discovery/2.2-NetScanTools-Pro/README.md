# 2.2: Port and Service Discovery using NetScanTools Pro

## Objective
Explore port/service discovery capabilities of NetScanTools Pro against an authorized target.

# INSTALLATION OF NETSCAN TOOLS PRO
1. In Windows vm open browser paste below link
https://www.netscantools.com/nstprodemorequestform.html

2. It will ask some details enter those required details and then download and install it.

## Procedure
1. Launch the application.
2. In Active Discovery Tools, Select Port Scanner
3. Enter target ip address use Metaspolit ip address.
4. select Scan Common ports.
5. Record open ports, protocol and service information.
