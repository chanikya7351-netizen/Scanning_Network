# 2.1: Port and Service Discovery using MegaPing

## Objective
Use MegaPing in an authorized lab to identify reachable hosts and TCP/UDP services.

## Procedure
1. Install MegaPing on the designated Windows lab system.
2. Enter only the authorized target IP/range.
3. Select the port scanning functionality.
4. Configure a small lab port range first.
5. Start the scan.
6. Record open ports and any service information shown.

## Suggested ports
```text
21, 22, 23, 25, 53, 80, 110, 139, 443, 445, 3389
```
OR ELSE USE DEFAULT PORTS IN MEGAPING
