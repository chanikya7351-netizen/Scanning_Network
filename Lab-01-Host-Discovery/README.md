# Lab 01: Perform Host Discovery

## Objective
Identify live systems in an authorized network using Nmap and Angry IP Scanner.

## Sub-Labs
- [1.1 Nmap](1.1-Nmap/README.md)
- [1.2 Angry IP Scanner](1.2-Angry-IP-Scanner/README.md)

## Concepts
Host discovery, ARP, ICMP, TCP SYN/ACK probes, UDP discovery, IP/MAC addressing, CIDR notation.

## Suggested topology
```text
Kali Linux (scanner) ---- Isolated Network ---- Windows/Linux target
```

Example network: `192.168.56.0/24`
